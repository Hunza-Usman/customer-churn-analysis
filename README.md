📊 Customer Churn Analysis Dashboard
This project analyzes customer churn behavior using Power BI to identify key drivers of customer retention and attrition in a telecom dataset.

🛠 Tools Used
Power BI
DAX (Data Analysis Expressions)
Data Cleaning & Transformation
Data Visualization

🎯 Objective
To understand customer churn patterns and identify factors influencing customer retention.

📈 Key Insights
Customers with low tenure are more likely to churn
Payment method significantly impacts churn behavior
Higher monthly charges increase churn risk
Customer segmentation helps identify at-risk groups

📊 Dashboard Features
KPI cards (Total Customers, Churned Customers, Churn Rate, Avg Monthly Charges)
Tenure vs Churn analysis
Payment Method impact on churn
Interactive slicer for filtering data
Pie chart for churn distribution
